# WAGRAM/IO Home Assistant Add-ons

## KNX Forensics

Records your KNX bus, compares it with the ETS project and shows what is wrong – with evidence and specific advice. Free version included; KNX Forensics Pro is unlocked with a licence key from [wagramio.at](https://wagramio.at).

### Installation
1. In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**
2. Add `https://github.com/wagramio/home-assistant-addons`
3. Install **KNX Forensics**, start it and open it from the sidebar.

Supported: 64-bit systems (amd64, aarch64 – e.g. Raspberry Pi 4/5, Home Assistant Green/Yellow).
